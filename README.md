# إمساكية - Imsakia

A comprehensive Islamic Flutter application designed to be a daily companion for Muslims, featuring a modern UI and reliable tools.

---

## Core Features

### Prayer Times
- Accurate daily prayer timings based on user location
- Real-time countdown to the next prayer
- Automatic athan notifications with customizable sounds
- Support for different calculation methods and locations

### Holy Quran
- Full Quranic text with beautiful Arabic typography
- Advanced bookmarking system for easy navigation
- "Last Read" persistence to resume reading seamlessly
- Smooth, intuitive navigation between surahs

### Electronic Misbaha
- Interactive digital tasbih with haptic feedback
- Session counters and total daily tracking
- Beautiful animations and responsive design
- Reset functionality with confirmation dialog

### Azkar & Fiqh
- Comprehensive collection of daily supplications (Azkar)
- Progress tracking for completed dhikr sessions
- Educational sections on fasting jurisprudence (Fiqh al-Siyam)
- Categorized azkar for different times and occasions

### Dynamic Themes
- Professional Light mode for daytime use
- Elegant Dark mode for nighttime reading
- Smooth theme transitions
- Optimized contrast for both modes

---

## Tech Stack

- Flutter - Cross-platform UI framework
- Provider - State management for reactive UI
- Shared Preferences - Local data persistence
- Google Fonts - Arabic typography (Tajawal, Amiri)

## Getting Started

### Prerequisites
- Flutter SDK (version 3.0 or higher)
- Android Studio / Xcode
- Git

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/imsakia.git
   cd imsakia
   ```

2. Install dependencies
   ```bash
   flutter pub get
   ```

3. Run the application
   ```bash
   flutter run
   ```

### Build for Production

```bash
# Android
flutter build apk --release

# iOS
flutter build ios --release
```
